I'm also learning cybersecurity with an ethical, defensive mindset: understanding how things break so I can build them to hold up.

## 🔐 Cybersecurity learning lab

> This is a **learning roadmap**, not a list of credentials. I practice only on systems I own or on platforms that explicitly allow it.

| Track | What I'm studying | Authorized practice and resources |
|---|---|---|
| 🌐 **Web security** | Common web vulnerabilities and how to prevent them | [OWASP Top 10](https://owasp.org/www-project-top-ten/) · [PortSwigger Web Security Academy](https://portswigger.net/web-security) |
| 📡 **Networking** | TCP/IP, DNS, HTTP, how traffic flows | [TryHackMe](https://tryhackme.com) · [Hack The Box Academy](https://academy.hackthebox.com) |
| 🐧 **Linux** | Command line, permissions, services | [Linux Journey](https://linuxjourney.com) · [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) |
| 🧱 **Secure coding** | Input validation, auth, safe API design | [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) |
| 🛡️ **Defensive security** | Hardening, logging, monitoring basics | [TryHackMe](https://tryhackme.com) · [picoCTF](https://picoctf.org) |

**Roadmap**

- [ ] Finish a structured web security path
- [ ] Solidify networking fundamentals
- [ ] Harden a personal Linux setup
